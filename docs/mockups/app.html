Макет: проверка программы

Третья вкладка рядом с «Сайт» и «Стабильность». Человек выбирает запущенную программу, повторяет то, что не работает, а whynet записывает, куда она подключается, и проверяет каждый сервер. Данные — Discord у провайдера без VPN и без обхода (как у Ильи на Билайне).
  • Выбор — список запущенных программ, сверху те, у кого есть окно. Браузеры внизу, с подсказкой про проверку сайта.
  • Запись — серверы появляются на ходу; видно, что у программы зависло или оборвалось. «Готово», когда повторил.
  • Результат — шаги слева, вердикт справа, как у проверки сайта; в «Подробнее» — таблица серверов.

Discord блокируют по имени

Его главные серверы — gateway.discord.gg, discord.com, cdn.discordapp.com — отвечают, но как только соединение называет их имя, его обрывают. С другим именем те же серверы отвечают нормально. Так работает блокировка через DPI у провайдера.

✗скорее всего

Discord ломается на пути через роутер

Все его соединения идут через прокси роутера (fake-ip) и там обрываются. Проверь, что discord.gg, discord.com, discordapp.com и discord.media есть в списке VPN на роутере.

Как это работает

Запись: каждые 250 мс whynet читает таблицу TCP-соединений Windows (без прав администратора) и собирает их по серверам. Имена: из DNS-кэша Windows, если он доступен; иначе из сертификата сервера; иначе обратный DNS. Проверка: пинг на тот же порт (5 попыток), для TLS — имя против нейтрального имени, покрытие zapret (списки имён, ipset, Game Filter). Вердикт — отдельный файл правил; всё попадает в отчёт для ИИ.
