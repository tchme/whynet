Макет: «Сеть Windows»

Четвёртая вкладка. Человек нажимает одну кнопку: whynet осматривает саму Windows (адаптер, адрес, DNS, прокси, hosts, TCP, часы), показывает, что сломано, и одной кнопкой чинит найденное, сохранив старые значения. Данные — ПК автора (кабель, роутер с fake-ip, hosts из сборки zapret, MTU 1400) плюс придуманные поломки для примера: мёртвый прокси, устаревшие строки в hosts, кабель на 100 Мбит/с.
  • Проверка — около 15 секунд, без прав администратора; области отмечаются по ходу.
  • Найденное — все проблемы списком, а не один вердикт: ✗ — чиню, ! — совет, i — просто знать. Что в порядке — свёрнуто.
  • Починить — одна кнопка, список действий виден заранее, права администратора спрашиваю один раз. Потом повторная проверка и «Вернуть как было».

7 · «Не помогло?» — глубокий сброс этап 2

Глубокий сброс сети

То, что советуют на форумах: netsh winsock reset и netsh int ip reset. Возвращает сетевые настройки Windows к заводским. Помогает, когда сломано то, чего проверка не видит. Нужна перезагрузка.

Что сотрётся на этом компьютере
  • MTU 1400 на Ethernet → станет 1500
  • Настройки адаптеров OpenVPN TAP и DCO (сами адаптеры останутся)
  • Ручных IP-адресов и DNS нет — терять нечего
  • Сторонних прослоек Winsock нет

Всё из списка сохраню. После перезагрузки открой whynet — предложу вернуть. «Сброс сети» из параметров Windows не предлагаю: он удаляет VPN-адаптеры.
